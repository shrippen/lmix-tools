# lmix tools

Linux tools for NDI and OMT: monitor, test patterns, screen capture,
virtual camera, discovery, analysis, audio bridge and recorder. One code
base, one app with views, each view also as its own window or headless
service.

Sibling of [lmix](https://github.com/shrippen/lmix), the live mixer and
show controller; both share the GStreamer elements and parts of the UI.

Status: planning. Requirements: `docs/LASTENHEFT.md`.
